# Skin-Cancer-Classification
This project presents a deep learning-based skin cancer classification system using the DenseNet121 architecture and transfer learning techniques. The model is trained on a multi-class dermoscopic image dataset containing nine different categories of skin lesions. Image preprocessing and augmentation techniques such as rotation, zooming, shearing, and horizontal flipping are applied to improve model generalization and reduce overfitting. The architecture uses DenseNet121 as the feature extraction backbone along with fully connected layers for classification. Adam optimizer is used for training, along with regularization and callback techniques including EarlyStopping, ReduceLROnPlateau, and ModelCheckpoint to improve performance and stability during training. The system is evaluated using accuracy, loss curves, and confusion matrix analysis for effective skin cancer prediction.
